The way it works now

You need Practical 5. You message a friend, wait for a reply, receive blurry photos in a chat, and scroll back through a hundred messages to find them again next week. Every classmate does the same thing, and the same files get sent over and over.

The way it works here

The admin uploads once. Everyone else opens the subject, picks the practical number, and downloads the photos and the code. Nothing gets lost in a chat.

How it works

  1. 1

    Pick a subject

    Five subjects are ready on day one. Add more any time.

  2. 2

    Open a practical

    Practicals are listed by number, so Practical 5 is always where you expect it.

  3. 3

    Grab what you need

    Switch between Images and Code. Download the photos, the code, or both, as separate files.

What you get

Photos, readable

Photos are shrunk when they are uploaded, so they stay clear and load fast on a phone.

Code with colours

Programs show with syntax colours and a one-click copy button.

Two separate downloads

Download all photos of a practical as one zip, and all code as another.

Search

Type "practical 5 PPS" or a word from a program and jump straight to it.

Live for everyone

When the admin adds something, it shows up for you without reloading.

Read-only for students

Only the admin can add or remove content, so the shelf stays tidy and nothing disappears by accident.
